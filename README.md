# PT-Syududu--Sistem-Pengelolaan-Data-Cuti-Karyawan
Latihan Responsi AlgoPT. Syududu adalah perusahaan fashion dan perawatan kecantikan milik Najasyi yang bergerak di bidang penjualan kosmetik dan skincare. Pihak perusahaan ingin memiliki sistem digital sederhana yang bisa membantu pengelolaan data cuti karyawan secara lebih efisien.
